## السلوك النهائي

لا توجد قيمة ثابتة عامة لمدة الفيديو. يحدد محتوى الحلقة المدة المناسبة؛ فـ Short بسيط يبقى قصيراً، بينما الدرس أو المباراة أو السرد الطويل يتوسع تلقائياً. يمكن استخدام `durationInSeconds` كحد أدنى تحريري اختياري لحلقة تحتاج مساحة إضافية، لكنه ليس مطلوباً.
