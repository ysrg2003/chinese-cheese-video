## Description

```text
Xiangqi Lab is the strategy lab for Chinese Chess (Xiangqi / 象棋).

Learn from the first setup to real tactics, openings, endgames, puzzles, and complete annotated games. Every lesson puts the position on the board, explains the idea clearly, and gives you a move to remember.

English and 简体中文 editions are published separately and clearly labelled — one language per video, with no mixed narration.

Start here: What Is Xiangqi? Then follow Piece Academy, First Games, Tactics, Puzzle Ladder, Full Games, and Xiangqi vs Other Board Games.

Learn Xiangqi. See the tactic. Play the whole game.
```

## Operational exclusions

The launch configuration must not include Arabic narration, Arabic captions, Arabic subtitles, Arabic thumbnail text, female voices, unverified external links, personal contact details, API keys, credentials, or copied third-party games without rights verification.
